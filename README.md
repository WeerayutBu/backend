# backend

Learn to build reliable backend services through focused code and projects.

## Projects

Each project applies the most relevant and important techniques.

1. **[REST API](00P1-project-rest-api/)** — FastAPI, validation, authentication, PostgreSQL, transactions, logging, and integration tests.
2. **[LLM API](00P2-project-llm-api/)** — FastAPI, async model calls, queues and workers, timeouts, retries, caching, logging, and integration tests.

Type hints, exceptions, data classes, dependency management, and project structure.
